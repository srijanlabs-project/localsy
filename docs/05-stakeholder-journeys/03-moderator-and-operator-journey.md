# 1. Goal

Keep platform data accurate, safe, and trustworthy.

# 2. Operator Journey

1. operator reviews imports, corrections, and geography issues
2. operator fixes mapping, taxonomy, and listing quality issues
3. operator escalates suspicious or high-risk items

# 3. Moderator Journey

1. moderator reviews pending listings and flagged content
2. moderator approves, rejects, or requests changes
3. moderator reviews abuse and policy issues

# 4. Product Requirements Implied

- strong queue design
- auditability
- duplicate review tools
- escalation and governance controls
