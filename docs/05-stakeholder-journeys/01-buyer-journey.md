# 1. Goal

Help a buyer discover the right local business and take action quickly.

# 2. Primary Journey

1. buyer lands on locality-aware page or selects locality manually
2. buyer searches or browses by category
3. buyer compares listings using reviews, trust, and basic details
4. buyer opens listing detail
5. buyer unlocks contact or submits an inquiry
6. buyer may save the listing or submit a review later

# 3. Key Friction Points

- wrong locality context
- too many low-quality listings
- contact reveal friction
- weak trust signals

# 4. Product Requirements Implied

- strong locality routing
- fast discovery and filtering
- reliable listing details
- OTP-gated but smooth contact unlock
- review-backed trust
