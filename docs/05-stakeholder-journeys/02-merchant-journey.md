# 1. Goal

Help a merchant join the platform, improve visibility, and convert leads.

# 2. Primary Journey

1. merchant discovers claim or submit-business CTA
2. merchant creates or claims listing
3. merchant passes verification and approval
4. merchant enriches profile, offers, and assets
5. merchant receives leads and manages follow-up
6. merchant upgrades visibility through paid options where useful

# 3. Key Friction Points

- unclear approval process
- weak proof of value
- limited lead visibility
- difficult content management

# 4. Product Requirements Implied

- clean onboarding and claim flow
- merchant workspace
- CRM and insights
- monetization tied to clear outcomes
