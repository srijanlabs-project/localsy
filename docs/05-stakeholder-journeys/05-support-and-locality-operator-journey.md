# 1. Purpose

This journey describes how support teams and locality operators keep Localisy reliable and trustworthy at the ground level.

# 2. Support Journey

1. receive issue, complaint, or clarification request
2. identify user, listing, ad, or locality context
3. inspect activity, status, and audit history
4. resolve directly or escalate to ops, moderation, or engineering
5. close with traceable outcome

# 3. Locality Operator Journey

1. review locality health
2. improve listing quality and coverage
3. resolve duplicate, trust, or routing issues
4. maintain locality content and highlights
5. monitor merchant and advertiser performance signals

# 4. Success Measures

- faster issue resolution
- lower unresolved moderation backlog
- higher locality listing quality
- better trust and response outcomes
