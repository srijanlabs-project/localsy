# 1. Purpose

Define how Localisy captures consent, protects PII, and enforces data-handling rules.

# 2. Consent Types

- OTP consent
- marketing consent
- WhatsApp consent
- policy acceptance where required

# 3. Required Controls

- consent text must be tied to the action being taken
- consent events must be auditable
- restricted contact data must not be exposed without passing policy rules
- retention behavior must be defined for sensitive operational records

# 4. Rights Handling

- deletion requests
- export requests
- grievance or complaint intake
- takedown requests

# 5. Audit Focus

- consent captured
- consent withdrawn
- data-rights request opened
- data-rights request completed
