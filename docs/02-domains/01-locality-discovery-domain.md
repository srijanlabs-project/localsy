# 1. Domain Purpose

This domain covers how Localisy helps buyers discover businesses within locality, city, and pincode context.

# 2. Core Capabilities

- locality routing
- search and browse
- listing pages
- SEO landing pages
- trust and review visibility

# 3. Main Business Questions

- how does a user reach the right locality?
- how does a user discover the right business quickly?
- how do search, SEO, and listing pages work together?
