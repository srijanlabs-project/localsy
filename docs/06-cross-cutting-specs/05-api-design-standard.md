# 1. Core Principles

- REST-first for operational flows
- explicit locality or scope context
- clear error responses
- audit for sensitive mutations

# 2. Conventions

- versioned APIs under `/api/v1`
- stable IDs
- paginated collection responses
- typed error codes and friendly messages
