# 1. Channels

- OTP/SMS
- email
- WhatsApp
- in-app or dashboard notices

# 2. Categories

- transactional
- trust and moderation
- lead and merchant activity
- operational alerts

# 3. Rules

- transactional messages take precedence over promotional messages
- notifications must respect consent and policy
- delivery state should be logged
