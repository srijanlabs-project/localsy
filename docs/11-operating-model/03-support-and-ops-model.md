# 1. Internal Roles

- admin
- operator
- moderator
- support
- growth operator

# 2. Responsibilities

- admins own platform-wide governance
- operators own data correctness
- moderators own approvals and flags
- support handles user and merchant exceptions
- growth operators own SEO and campaign performance

# 3. Escalation Model

- low-risk data fixes stay with operator
- trust or abuse cases escalate to moderator or admin
- legal or privacy cases escalate through compliance workflows
