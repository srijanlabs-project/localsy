# 1. Terms

- `Locality`: primary operational tenant
- `City`: aggregation layer across localities
- `Canonical Listing`: approved master record for a business
- `Claim Listing`: merchant ownership request over an existing listing
- `Resolved Homepage`: computed page payload for a context such as locality and device
- `Sponsored Listing`: paid visibility placement
