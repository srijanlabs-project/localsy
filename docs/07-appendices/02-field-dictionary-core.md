# 1. Core Business Fields

| Field | Meaning |
|---|---|
| `id` | system identifier |
| `name` | listing name |
| `localityId` | primary locality tenant |
| `cityId` | city aggregation reference |
| `areaId` | primary area reference |
| `categoryId` | master category |
| `subcategoryId` | master subcategory |
| `status` | lifecycle state |
| `phone` | primary public phone |
| `website` | business website |
