# 1. Purpose

This appendix catalogues shared business rules used across Localisy.

# 2. Rule Families

- locality-first discovery rules
- trust-first ranking rules
- sponsored visibility and labeling rules
- duplicate and canonicalization rules
- advertiser approval and compliance rules
- OTP and contact-visibility rules
- home-based business privacy rules
- public-service prioritization rules

# 3. Usage

- parent module specs should reference this appendix for shared rules
- deep specs should define exceptions or workflow-specific logic
- engineering and QA should use this as a consistency baseline
