# 1. Purpose

This appendix defines the most important product, growth, trust, and advertiser metrics for Localisy.

# 2. Buyer Experience Metrics

- search CTR
- zero-result rate
- query-to-contact unlock
- query-to-lead
- listing detail conversion
- repeat locality usage

# 3. Trust and Quality Metrics

- verified listing ratio
- invalid contact rate
- duplicate resolution turnaround
- review authenticity rate
- support resolution time

# 4. Advertiser Metrics

- impressions
- clicks
- CTR
- contact unlock rate
- lead rate
- cost per click
- cost per lead
- creative rotation performance

# 5. AI and WhatsApp Metrics

- answer accuracy
- citation coverage
- multilingual quality
- response latency
- WhatsApp resolution rate
- fallback rate

# 6. Rules

- every metric should have a single calculation owner
- dashboard labels should match these definitions
- changes to metric formulas should be versioned
