# 1. Purpose

This guide explains how to navigate the Localisy documentation library quickly.

# 2. How to Use the Library

- start with [00-library-index.md](/D:/localsy/docs/00-master-index/00-library-index.md) for top-level navigation
- use `03-module-specifications` for capability-level understanding
- use `08-submodule-specifications` for build-ready deep specs
- use `09-product-backlog` for execution status and delivery tracking
- use `10-ui-ux-architecture` for screen, IA, and UX references
- use `07-appendices` for shared reference materials

# 3. Reading Paths

- product or strategy review: platform overview -> domains -> module specs
- design review: journeys -> UI/UX architecture -> module specs
- engineering implementation: module specs -> deep specs -> cross-cutting standards -> appendices
- QA review: module specs -> testing strategy -> delivery checklists -> appendices
