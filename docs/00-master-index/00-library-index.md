# 1. Purpose

This index is the entry point for the Localisy documentation library.

The library is intended to become the single source of truth for:

- business stakeholders
- product managers
- operations teams
- merchant growth teams
- UX designers
- frontend and backend engineers
- QA teams
- data and AI teams
- security and compliance teams

# 2. Core Library Structure

- `00-master-index`
  - blueprint, index, writing rules, navigation, roadmap
- `01-platform-overview`
  - product vision, operating model, platform architecture, market positioning
- `02-domains`
  - locality operations, merchant growth, directory discovery, AI knowledge, governance
- `03-module-specifications`
  - parent module specifications
- `04-submodule-catalog`
  - detailed module, sub-module, and sub-sub-module inventory
- `05-stakeholder-journeys`
  - buyer, merchant, moderator, operator, admin, locality operator, support
- `06-cross-cutting-specs`
  - permissions, workflows, notifications, audit, AI, API, analytics, compliance
- `07-appendices`
  - glossary, field dictionary, event catalogue, report inventory, state machines
- `08-submodule-specifications`
  - deep build-ready specifications for high-complexity L3 topics
- `09-product-backlog`
  - release slicing, epic register, dependency map
- `10-ui-ux-architecture`
  - information architecture, page inventory, component and flow specs
- `11-operating-model`
  - locality tenancy, city aggregation, merchant commercial model, support model
